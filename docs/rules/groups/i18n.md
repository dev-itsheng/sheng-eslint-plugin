# i18n

这组规则只服务国际化项目。项目没有 i18n、没有翻译平台，也不需要把用户可见文案收敛到语言包时，可以先跳过这一组。

## 适用场景

i18n 规则守的是翻译资源的可维护性。翻译 key 要能被 IDE、扫描脚本和翻译平台静态读到；缺失 key 应该进入统一补文案流程；用户可见中文如果暂时还没有 key，也要先变成可见清单，而不是散落在组件里。

这组规则默认适合从 `warn` 开始。`@sheng/no-dynamic-i18n-t-key` 和 `@sheng/no-i18n-t-fallback` 更偏稳定约束，确认项目翻译函数名单后可以升成 `error`；`@sheng/no-chinese-user-text-literal` 更像迁移和盘点工具，适合按目录或 owner 范围逐步打开。

## 包含规则

| 规则 | 作用 |
| --- | --- |
| [`@sheng/no-dynamic-i18n-t-key`](../no-dynamic-i18n-t-key.md) | 要求 `t()` 的第一个参数保持字符串字面量，让工具链看得到真实 key。 |
| [`@sheng/no-i18n-t-fallback`](../no-i18n-t-fallback.md) | 禁止在调用点传 fallback，避免缺失 key 被局部兜底静默掩盖。 |
| [`@sheng/no-chinese-user-text-literal`](../no-chinese-user-text-literal.md) | 扫描运行时代码和模板里的用户可见中文，推动它们进入 i18n key 或文案清单。 |
